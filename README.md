# learning

Isiklik õpiruum: oskused ja materjalid selle kohta, mida õppida ja miks.

## Oskused

### `what-to-learn`

Aitab valida õppesuunda kahes etapis:

1. **Huvi** — mis mind päriselt huvitab, ilma et peaks põhjendama, kas sellega
   saab tööd
2. **Töö** — milline töö sobiks, ja mida konkreetsed ametikohad **tegelikult**
   nõuavad (päris töökuulutuste, mitte oletuste põhjal)
3. **Ristumine** — kus need kaks kattuvad, mis on puudu, ja üks väike katse,
   millega huvi odavalt kontrollida

Asukoht: `.claude/skills/what-to-learn/`

Käivitub ise, kui küsid midagi õppimise või eriala valiku kohta. Võid ka otse
kutsuda: `/what-to-learn`
